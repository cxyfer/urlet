# Intent

Owners need to control the thumbnail and text shown when sharing a short link to Discord and other social platforms. Support both HTTPS image URLs and direct raster uploads. User authorises plan followed by implementation, a PR and independent subagent review. No merge or deployment is included.

Success evidence: owner-only editor/API, explicit public-data notice, escaped OG/Twitter metadata for known social crawlers, normal browser flows, lifecycle-bound image URLs, atomic rejected updates, bounded image validation, six themes and three locales, required repository checks and independent review.
