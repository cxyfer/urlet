# Reflection

Container and canvas dimensions are insufficient for bounded raster validation: WebP may allocate from an inner frame before checking consistency, and GIF permits frames outside its screen by default. Check the relevant encoded frame descriptors before pixel decoding and limit concurrent decoding globally. A decoder buffer budget does not bound the whole process RSS.

Keep uploaded bytes in the existing SQLite backup boundary; read metadata without BLOBs. Preview fields are independently and explicitly public, including on password links. Do not infer public copy from private management fields or destinations. Treat independent review and actual browser computed styles as complementary to HTTP tests. Third-party SNS rendering and cache invalidation need external acceptance evidence.
